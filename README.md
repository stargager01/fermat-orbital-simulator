# 🌀 페르마 나선 오비탈 시뮬레이터 (Fermat Spiral Orbital Simulator)

주기율표의 118개 원소들의 오비탈 전자 구조를 '페르마 나선(Fermat Spiral)'을 이용해 직관적이고 아름답게 시각화한 웹 애플리케이션입니다.

## ✨ 주요 기능
* **인터랙티브 주기율표:** 118개 원소를 클릭하여 바로 확인 가능
* **오비탈 애니메이션:** s, p, d, f 블록 오비탈의 실시간 회전 시각화
* **상세 정보 제공:** 선택한 원소의 전자 배치, 최외각 양자수 정보 표시
* **수식 시각화:** 페르마 나선 수식 및 오비탈 레이어별 켜기/끄기 토글 지원

https://stargager01.github.io/fermat-orbital-simulator/

## 🚀 실행 방법
별도의 설치나 서버 구축이 필요 없습니다. 
저장소에 있는 `index.html` 파일의 코드를 복사하거나 다운로드하여 **웹 브라우저(크롬, 사파리 등)**에서 열기만 하면 바로 시뮬레이터가 실행됩니다.
